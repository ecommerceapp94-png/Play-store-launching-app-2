# MeetX Ultra Pro

An EXTREMELY large React Native + Expo demo app showcasing premium UI patterns,
deep navigation, and rich mock data — built end-to-end with TypeScript.

## What's inside

- **5 bottom tabs**, each with its own native stack navigator (Home, Meetings,
  Contacts, Schedule, Profile)
- **111 fully-styled screens** (~700 LOC each, ~84,000 LOC total) with deep
  navigation: every card, row and chip taps through to a richer detail screen
- **Up to 6 levels of navigation** depth on the in-call settings flow
- **Premium UI surfaces**: `LinearGradient` heroes, frosted `BlurView` glass
  cards, dual-shadow neumorphism cards, gradient buttons, animated tab bar
- **Reanimated 2** micro-animations on every press, looping hero blobs, spring
  physics on the tab bar
- **Haptic feedback** on every button and tappable row
- **Light + dark mode** with a smooth toggle, persisted to AsyncStorage
- **Floating AI assistant** powered by `@gorhom/bottom-sheet` with mocked
  responses on every screen
- **AsyncStorage persistence** for theme, favourites, search history, recent
  rooms, integrations, and more
- **Pull-to-refresh, skeleton loaders, infinite scroll** and toggles on every
  screen
- **120 contacts, 60 meetings, 40 recordings, 30 notifications** generated by
  a seeded PRNG so the data is deterministic across boots

## Stack

- React Native 0.81 + Expo SDK 54
- React 19, TypeScript 5.9 (strict)
- `@react-navigation/native` + native-stack + bottom-tabs
- `react-native-reanimated`, `react-native-gesture-handler`, `expo-blur`,
  `expo-linear-gradient`, `expo-haptics`, `@gorhom/bottom-sheet`,
  `@react-native-async-storage/async-storage`
- Path alias `@/*` resolves to `src/*` via `babel-plugin-module-resolver`

## Run it

```bash
npm install
npm run start          # Expo dev server
npm run ios            # iOS simulator
npm run android        # Android emulator
npm run web            # Web preview (limited animations support)
```

Type-check the entire 84k-LOC codebase with:

```bash
npx tsc --noEmit
```

## Project layout

```
src/
├── components/        # Reusable UI primitives (15 files)
├── hooks/             # useHaptics, ...
├── mock/              # Seeded mock data factory
├── navigation/        # Root + 5 stack navigators
├── screens/           # 111 screens organised by tab
│   ├── home/          (20 screens)
│   ├── meetings/      (19 screens)
│   ├── contacts/      (20 screens)
│   ├── schedule/      (19 screens)
│   ├── profile/       (28 screens)
│   └── incall/        (7 screens, 6 levels deep)
├── store/             # AppStoreProvider w/ AsyncStorage persistence
├── theme/             # Light + dark theme palettes & ThemeProvider
├── types/             # Domain models + navigator param lists
└── utils/             # format & PRNG helpers
scripts/
└── generate-screens.js   # Generator that re-emits all screen files
```

The bulk of the screens are produced by `scripts/generate-screens.js` so a
single template change can propagate across all 111 screens. Run
`node scripts/generate-screens.js` to regenerate them.
